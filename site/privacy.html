계정 데이터 안내

치유숲씨 웹사이트 계정을 만들 때 필요한 정보와 사용 방식을 안내합니다.

수집하는 정보

  • 회원가입 때 입력한 이름과 이메일 주소
  • 로그인 보안을 위해 단방향 해시 처리한 비밀번호와 세션 토큰
  • 자동 가입·로그인 제한을 위해 해시 처리한 접속 주소와 이메일 조합 (마지막 요청 이후 24시간이 지나면 다음 인증 요청 때 정리)

사용 목적

회원 계정 관리, 이메일 인증, 로그인 유지, 비밀번호 재설정, 비정상적인 가입·로그인 요청 제한에 사용합니다. 비밀번호 원문은 저장하지 않습니다.

저장과 이메일 발송

계정 정보와 인증 토큰은 Cloudflare D1 데이터베이스에 저장합니다. 로그인 세션은 30일 만료의 HttpOnly·Secure·SameSite 쿠키로 유지합니다. 인증 및 비밀번호 재설정 메일은 Resend를 통해 전달하며, 메일 발송에 필요한 이메일 주소와 메일 내용이 Resend에 전송됩니다. 메일 API 키는 Cloudflare의 비밀 설정에 보관합니다.

보관과 삭제

계정 정보는 계정이 유지되는 동안 보관합니다. 로그인 창의 회원 탈퇴를 누르면 현재 비밀번호를 확인한 뒤 계정, 세션, 인증 토큰을 삭제합니다. 만료되거나 사용한 인증 토큰과 오래된 보안 제한 기록은 정리합니다.
