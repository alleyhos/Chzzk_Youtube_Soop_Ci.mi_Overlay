01 / 하는 일

방송 중 필요한 것만
빠르게 확인하세요.

네 플랫폼을 같은 화면에서 관리하고, 오버레이는 방송 화면에 맞춰 직접 정리합니다.

01

채팅 통합

치지직 · YouTube · 숲 · 씨미 채팅을 한 오버레이에서 읽습니다.

CH / YT / SP / CM
02

시청자 수

플랫폼별 인원을 프로그램에서 확인하고, 오버레이 배지는 각각 이동합니다.

4 COUNTS
03

방송 화면에 맞춤

크기, 글자, 배경 투명도, 표시 줄 수와 색 테마를 조절합니다.

LAYOUT
04

게임 중 빠른 조작

오버레이를 숨기거나 마우스 클릭을 통과시키는 단축키를 제공합니다.

CTRL + ALT

02 / 시작하기

처음 연결은
세 단계면 됩니다.

  1. 01

    실행 파일 받기

    최신 버전을 내려받아 압축을 풀고 프로그램을 실행합니다.

  2. 02

    방송 주소 입력

    플랫폼 연결에서 사용할 방송 또는 채팅 주소를 입력합니다.

  3. 03

    오버레이 조정

    채팅을 연결하고 위치와 글자 크기를 방송 화면에 맞춥니다.
