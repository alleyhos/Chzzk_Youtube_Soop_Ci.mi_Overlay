기능

방송 중 손이 덜 가도록
필요한 것만 모았습니다.

채팅과 시청자 수를 같은 오버레이에서 다루고, 위치와 표시 방식을 방송 환경에 맞춰 저장합니다.

01

채팅 통합

연결한 플랫폼의 공개 채팅을 시간순으로 표시합니다. 이모티콘과 플랫폼 배지도 함께 보여줍니다.

CH · YT · SP · CM
02

시청자 수

플랫폼별 인원을 확인하고, 숫자 배지를 각각 원하는 위치로 옮길 수 있습니다.

개별 위치 저장
03

화면에 맞춘 표시

글자 크기, 줄 수, 투명도와 테마를 조절합니다. 위치와 크기는 다음 실행에도 기억합니다.

설정 자동 저장
04

방송 중 빠른 조작

Ctrl + Alt + O로 숨김을 전환하고, Ctrl + Alt + P로 클릭 통과를 켭니다.

전역 단축키
