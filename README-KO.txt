# 치지직 + YouTube + SOOP 채팅 오버레이

Windows 10/11 원컴 방송용 투명 채팅 오버레이입니다. 치지직, YouTube, SOOP 채팅을 한 창에 표시합니다.

## 실행

- 치지직, YouTube, SOOP 중 필요한 플랫폼만 연결할 수 있습니다.
- 입력한 링크와 화면 설정은 이 PC에 저장됩니다. 자동 연결 여부는 방송 동작 카테고리에서 선택할 수 있습니다.
- 설정은 **플랫폼 연결 / 레이아웃 / 테마 / 채팅 표시 / 방송 동작 / 단축키 / 앱 정보** 카테고리로 나누어져 있습니다.

## 치지직 연결

1. **플랫폼 연결** 카테고리의 치지직 주소 칸에 채널 또는 라이브 주소를 붙여넣습니다. 예: `https://chzzk.naver.com/live/채널ID`
2. **치지직 연결**을 누릅니다. 앱 등록, 앱 ID/Secret, OAuth 로그인은 필요하지 않습니다.
3. 방송이 꺼져 있으면 앱이 채널을 확인하며 기다리고, 방송이 시작되면 채팅에 자동 연결합니다.

치지직은 공개 채팅 웹 연결을 이용하는 비공식 방식입니다. 서비스 변경이나 접속 제한에 따라 연결 방식이 바뀌거나 일시적으로 실패할 수 있습니다. 앱은 자동 재연결을 시도합니다.

## YouTube 연결 — Google Cloud 및 결제 카드 불필요

1. **플랫폼 연결** 카테고리의 YouTube 주소 칸에 라이브 방송 또는 채팅 팝아웃 주소를 붙여넣습니다.
2. **YouTube 연결**을 누릅니다.
   - 방송 페이지: `https://www.youtube.com/watch?v=동영상ID`
   - 라이브 주소: `https://www.youtube.com/live/동영상ID`
   - 채팅 팝아웃: `https://www.youtube.com/live_chat?v=동영상ID&is_popout=1`
   - 11자리 동영상 ID만 입력해도 됩니다.
3. **설정 저장**을 누르면 다음 실행 때 저장된 방송 주소로 연결합니다.

이 앱은 공개 웹 채팅 인터페이스를 이용합니다. 채팅 확인 간격은 1초로 설정했지만, YouTube의 처리나 네트워크 지연에 따라 실제 표시까지 더 걸릴 수 있습니다. YouTube의 공식 Data API는 아니므로 페이지/내부 형식 변경이나 접속 제한이 생기면 연결이 실패할 수 있습니다. 새 방송마다 주소가 달라지면 입력 주소도 바꿔 주세요. 기본 이모티콘과 일부 이미지 이모티콘을 표시합니다.

## SOOP 연결

1. **플랫폼 연결** 카테고리의 SOOP 칸에 `play.sooplive.com/채널ID` 방송 주소 또는 채널 ID를 입력합니다.
2. **SOOP 연결**을 누릅니다. 방송이 꺼져 있으면 10초마다 다시 확인합니다.

공개 라이브 채팅의 내부 연결 형식을 사용합니다. SOOP의 공식 외부 개발자 채팅 API가 아니며, 서비스 변경에 따라 연결이 중단될 수 있습니다. 일반 메시지는 오버레이에 표시하고, SOOP 이모티콘은 현재 텍스트 표시로 대체합니다. SOOP 채팅 서버의 바이너리 WebSocket 프레임도 처리합니다.

## 오버레이 조작

- `Ctrl+Alt+O`: 오버레이 숨김/표시
- `Ctrl+Alt+P`: 게임 클릭 통과 켜기/끄기
- 오버레이 위쪽을 드래그해 위치를 옮깁니다.
- 게임은 창 모드 또는 테두리 없는 창 모드를 권장합니다. 독점 전체 화면은 오버레이를 덮을 수 있습니다.
- OBS 게임 캡처는 별도 오버레이 창을 제외할 수 있습니다. 디스플레이 캡처는 오버레이까지 방송에 잡힐 수 있습니다.

## 데이터 및 개인정보

- 입력한 주소와 화면 설정은 `%LOCALAPPDATA%\ChzzkOverlay\settings.json`에 저장됩니다.
- 채팅은 이 PC에서 각 플랫폼에 직접 연결합니다. 별도 중계 서버는 사용하지 않습니다.
- 로그인 토큰이나 앱 Secret은 저장하거나 요청하지 않습니다.

## 설정 카테고리

- **플랫폼 연결**: 치지직, YouTube, SOOP 주소와 연결 상태
- **레이아웃**: 배경 투명도, 채팅 줄 수/글자 크기, 창 너비/높이
- **테마**: 4가지 오버레이 색상 프리셋
- **채팅 표시**: 익명 표시, 플랫폼 배지, 수신 시각, 연결 전 샘플 표시
- **방송 동작**: 자동 연결, 시작 시 오버레이, 클릭 통과, 항상 위
- **단축키**: 전역 단축키 활성/비활성
- **앱 정보**: 연결 상태와 커뮤니티 링크
