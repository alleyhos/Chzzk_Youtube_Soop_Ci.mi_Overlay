# 치유숲 v1.1.0
### CHZZK · YouTube · SOOP 통합 채팅 & 시청자 수 오버레이

Windows 10 / 11 원컴 방송 환경을 위한 통합 오버레이 프로그램입니다.

치지직, YouTube Live, SOOP 중 원하는 플랫폼을 연결하여 채팅과 플랫폼별 시청자 수를 하나의 화면에서 확인할 수 있습니다.

---

## 주요 기능

- **멀티 플랫폼 지원** — 치지직, YouTube Live, SOOP
- **통합 채팅 오버레이** — 여러 플랫폼의 채팅을 한 화면에서 확인
- **플랫폼별 시청자 수** — 각 플랫폼의 공개 시청자 수 표시
- **자유로운 화면 배치** — 오버레이와 시청자 수 배지 위치 조절
- **클릭 통과 모드** — 게임 플레이 중 오버레이 조작 방지
- **자동 재연결** — 연결이 끊어진 경우 재연결 시도
- **개인 설정 저장** — 다음 실행에도 설정 유지

## 프로그램 실행

1. 배포된 ZIP 파일의 압축을 풉니다.
2. `치유숲.exe`를 실행합니다.
3. 설정의 **플랫폼 연결** 메뉴로 이동합니다.
4. 사용할 플랫폼의 방송 주소를 입력합니다.
5. 해당 플랫폼의 연결 버튼을 누르면 됩니다.

## 플랫폼 연결 방법

### 치지직 (CHZZK)

1. 플랫폼 연결 메뉴에서 치지직 채널 또는 라이브 주소를 입력합니다.
2. `치지직 연결`을 누릅니다.

주소 예시:
`https://chzzk.naver.com/live/채널ID`

방송이 꺼져 있으면 채널 상태를 확인하며 대기하고, 방송이 시작되면 채팅 연결을 시도합니다.

### YouTube Live

1. YouTube 라이브 방송 주소 또는 채팅 팝아웃 주소를 입력합니다.
2. `YouTube 연결`을 누릅니다.
3. 설정 저장을 누르면 다음 실행 시에도 주소가 유지됩니다.

지원 주소 형식:

- `https://www.youtube.com/watch?v=동영상ID`
- `https://www.youtube.com/live/동영상ID`
- `https://www.youtube.com/live_chat?v=동영상ID&is_popout=1`
- 11자리 동영상 ID

### SOOP

1. 플랫폼 연결 메뉴에서 SOOP 방송 주소 또는 채널 ID를 입력합니다.
2. `SOOP 연결`을 누릅니다.

주소 예시:
`play.sooplive.com/채널ID`

방송이 오프라인인 경우 방송 상태를 다시 확인합니다.

## 플랫폼별 시청자 수

v1.1.0부터 플랫폼별 시청자 수 표시 기능을 지원합니다.

1. 플랫폼 연결 메뉴에서 각 플랫폼의 방송 주소를 저장합니다.
2. 설정의 **시청자 수** 메뉴로 이동합니다.
3. 표시할 플랫폼을 선택합니다.
4. 오버레이에 표시된 배지를 직접 드래그하여 위치를 조절합니다.

- 플랫폼별 배지 위치 개별 저장
- 선택한 플랫폼 배지 위치 초기화
- 30초 간격으로 시청자 수 갱신
- 공개된 시청자 수가 없으면 `—`로 표시

클릭 통과 모드에서는 배지를 드래그할 수 없습니다. `Ctrl+Alt+P`로 클릭 통과를 해제한 뒤 조작하세요.

---

## 오버레이 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl + Alt + O` | 오버레이 숨김 / 표시 |
| `Ctrl + Alt + P` | 게임 클릭 통과 켜기 / 끄기 |

오버레이 상단을 드래그하여 위치를 이동할 수 있습니다.

게임 화면은 창 모드 또는 테두리 없는 창 모드를 권장합니다. 독점 전체 화면에서는 게임이 오버레이를 덮을 수 있습니다.

### OBS 사용 안내

- 게임 캡처에서는 별도 오버레이 창이 제외될 수 있습니다.
- 디스플레이 캡처에서는 오버레이까지 방송 화면에 포함될 수 있습니다.

## 설정 메뉴

현재 설정 카테고리는 다음과 같습니다.

1. 플랫폼 연결
2. 레이아웃
3. 테마
4. 채팅 표시
5. 시청자 수
6. 방송 동작
7. 단축키
8. 앱 정보

방송 주소와 화면 설정은 현재 PC에 저장되며, 자동 연결 여부는 방송 동작 메뉴에서 설정할 수 있습니다.

## 개인정보 및 보안

치유숲은 별도의 채팅 중계 서버를 사용하지 않고, 이 PC에서 각 플랫폼에 직접 연결합니다.

- 방송 주소와 화면 설정은 로컬 PC에 저장됩니다.
- 설정 저장 위치: `%LOCALAPPDATA%\ChzzkOverlay\settings.json`
- 로그인 토큰이나 앱 Secret을 요청하거나 저장하지 않습니다.
- Google Cloud API 키를 요구하지 않습니다.
- 별도의 자체 회원가입이나 계정 생성이 필요하지 않습니다.

각 플랫폼의 공개 웹 연결 방식을 사용하므로 서비스 정책, 접속 제한, 웹 페이지 구조 변경 등에 따라 연결이 일시적으로 중단될 수 있습니다.

## 알려진 제한 사항

- 치지직과 SOOP은 공식 외부 개발자 채팅 API가 아닌 공개 웹 연결 방식을 이용합니다.
- YouTube는 공개 웹 채팅 인터페이스를 이용합니다.
- 플랫폼의 정책, 접속 제한, 내부 연결 방식 변경에 따라 연결이 중단될 수 있습니다.
- YouTube 채팅 표시 시간은 네트워크와 플랫폼 처리 상황에 따라 지연될 수 있습니다.
- SOOP 이모티콘은 텍스트로 대체될 수 있습니다.
- 공개 시청자 수가 없거나 방송이 오프라인이면 숫자가 표시되지 않을 수 있습니다.
