# 치유숲씨 v1.1.1

치지직, YouTube, SOOP, 씨미의 라이브 채팅을 한 화면에 모으는 Windows 방송용 오버레이입니다. 플랫폼 주소를 입력해 연결하며, 채팅과 시청자 수 배지를 한 오버레이에서 조절할 수 있습니다.

## 주요 기능

- 치지직, YouTube, SOOP, 씨미 4개 플랫폼 채팅 통합
- 씨미는 공개 방송 주소를 입력해 영상 없이 채팅만 표시
- 플랫폼별 시청자 수를 하나의 오버레이에 표시하고 각각 위치 조절
- 일시적인 조회 실패가 발생해도 마지막 정상 시청자 수 유지
- YouTube 시청자 수를 요청한 방송의 기본 정보에서 읽어 추천 영상 수치와 구분
- 오버레이 위치와 크기 저장, 채팅 줄 수·글자 크기·배경 투명도 조절
- 블랙, 아이보리, 미드나잇 블루, 딥 민트 테마
- 익명 표시, 플랫폼 배지, 수신 시각, 연결 전 미리보기 설정
- 항상 위, 클릭 통과, 자동 연결, 전역 단축키 지원
- 설정 화면 카테고리 정리, 시작 로딩 화면과 화면 전환 효과

## 실행 및 연결

1. 최신 배포 파일을 받아 압축을 풉니다.
2. `치유숲씨.exe`를 실행합니다.
3. 플랫폼 연결에서 사용할 방송 또는 채널 주소를 입력하고 연결합니다.
4. 오버레이를 켜고 필요하면 설정 저장을 누릅니다.

### 주소 예시

- 치지직: `https://chzzk.naver.com/live/채널ID`
- YouTube: `https://www.youtube.com/watch?v=동영상ID` 또는 `https://www.youtube.com/live/동영상ID`
- SOOP: `https://play.sooplive.com/채널ID`
- 씨미: `https://ci.me/@채널주소/live`

YouTube 연결에는 Google Cloud 프로젝트, API 키, 결제 카드 등록이 필요하지 않습니다. 씨미는 공개 라이브 방송 주소에서 채팅을 읽으며 방송 영상은 표시하지 않습니다.

## 오버레이 조작

- 오버레이 상단을 드래그해 창을 이동합니다.
- 시청자 수 배지를 각각 드래그해 원하는 곳에 놓습니다. 위치는 저장됩니다.
- `Ctrl + Alt + O`: 오버레이 숨김/표시
- `Ctrl + Alt + P`: 게임 클릭 통과 켜기/끄기
- 클릭 통과 상태에서 배지를 옮길 때는 먼저 `Ctrl + Alt + P`로 해제합니다.
- 게임은 창 모드 또는 테두리 없는 창 모드 사용을 권장합니다.

## 시청자 수 안내

시청자 수는 앱에서 자동으로 다시 확인합니다. 일시적인 네트워크·플랫폼 응답 오류로 새 값을 가져오지 못하면 화면의 마지막 정상 숫자를 유지합니다. 방송이 오프라인이거나 플랫폼에서 시청자 수를 공개하지 않는 경우 새 숫자를 받을 수 없습니다. 플랫폼별 공개 방식에 따라 조회 주기와 제공 여부가 다를 수 있습니다.

## 저장 데이터와 개인정보

방송 주소와 화면 설정은 이 PC의 `%LOCALAPPDATA%\ChzzkOverlay\settings.json`에 저장됩니다. 채팅은 각 플랫폼에 직접 연결하며 별도 중계 서버를 사용하지 않습니다. 로그인 토큰, 앱 Secret, Google Cloud API 키를 요구하거나 저장하지 않습니다.

## 연결 관련 참고

치지직, YouTube, SOOP, 씨미의 공개 웹 연결 방식을 이용합니다. 플랫폼의 내부 연결 방식, 공개 정보, 이용 제한이 바뀌면 채팅·이모티콘·시청자 수가 일시적으로 표시되지 않을 수 있습니다. 일부 플랫폼 이모티콘은 해당 서비스가 제공하는 이미지 형식에 따라 텍스트로 표시될 수 있습니다. 연결 문제가 계속되면 최신 버전으로 업데이트하고 방송 주소를 다시 확인해 주세요.
